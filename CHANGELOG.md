# Changelog

## 0.1.0 — 2026-11-03

- System Plex service controls through a native Linux tray icon.
- Passwordless start/stop for active local desktop users via a package-owned
  Polkit rule.
- Live service status, single-instance behavior, and a Plex web launcher.
- Colored and theme-aware monochrome icons with a saved appearance preference.
- Local Arch packaging, MIT license, and automated checks.
